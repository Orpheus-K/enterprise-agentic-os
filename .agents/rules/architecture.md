# 守住架构边界

- 复用主线：Go 模块化单体＋角色配置；Python 无状态计算；同一代码支持单机与集群。
- 组织仓库：遵循 [Monorepo 边界](../../enterprise-agentic-os-architecture/01-总体架构与工程边界.md)；应用消费共享包；各语言独立工具链。
- 隔离所有权：通过契约访问模块；禁止直接改写其他模块的表、状态或文件。
- 固定事实源：生产 PostgreSQL、轻量 SQLite；Channel 与缓存不承载唯一任务/授权事实。
- 约束驱动：遵守同一行为契约；不支持即拒绝启动；引入中间件先说明必要性与运维代价。
- 原子推进：同事务提交状态、事件、outbox；网络调用与长计算放在事务外。
- 防止重放：校验幂等键、版本、租约世代；未知写结果先核对，不盲重试。
- 固定版本：在途任务绑定 Revision；重放只使用记录/替身，不再次产生真实副作用。
- 绑定审批：核验来源、身份、权限、有效期与内容版本；修改后重算；Token 不等于授权。
- 重验权限：读取、调用与交付使用当前有效授权；撤权或不可确认时拒绝，不沿用旧许可。
- 过滤证据：检索出库前授权；隔离租户、缓存、重排及引用；群聊另验接收范围。
- 隔离执行：模型输出视为输入；凭证仅由网关代办；不可信代码进入受限沙箱。
- 最小采集：日志保留标识、版本、状态与摘要；禁止默认记录密钥、完整 Prompt 或客户正文。
- 精确核价：使用明确币种、精度与舍入规则；禁止浮点误差或模型心算决定业务金额。
- 保留恢复：幂等、审批等待、补偿、撤权校验属于正确性约束，不按“删除兜底”移除。
