# 维护统一版本

- 固定现场：记录制品、配置摘要、驱动、迁移与技能版本；先取证再修改。
- 缩小故障：用任务 ID、事件、trace 和外部结果定位失败边界；不以重启掩盖根因。
- 脱敏诊断：预览导出范围；剔除密钥；记录复现缺口；不自动外发客户资料。
- 修复根因：修改最小责任模块；添加对应回归；不追加无限重试或全局异常吞噬。
- 保持主线：客户差异通过配置、技能或认证驱动表达；补丁回主线，禁止长期核心分叉。
- 验证升级：检查契约、事件、快照和数据库兼容；保留在途任务与当前授权。
- 演练迁移：联合备份数据、文件、密钥与审计；校验恢复；切换保持单一有效执行方。
- 核对回退：确认旧程序可读数据；核对备份点之后外部副作用，不重复执行已成功业务。
- 锁定依赖：更新锁文件与物料清单；检查许可证、安全和离线构建；不在生产临时下载依赖。
- 区分授权：准备可审查补丁与部署步骤；本技能不额外授权生产切换、客户数据外发或不可逆迁移。
