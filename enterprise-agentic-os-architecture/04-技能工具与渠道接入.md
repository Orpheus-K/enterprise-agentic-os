# 04 技能工具与渠道接入

## 一、总述：业务声明与外部协议分别维护

技能表达业务 SOP，网关落实授权与协议转换，渠道适配器负责展示与事件接入。业务代码不直接拼接飞书或钉钉卡片，也不把 REST 参数配置当成业务规则的替代品。

## 二、渐进式技能与版本化资产

第一级只加载当前员工获准的技能名称、摘要与触发条件；第二级在匹配后加载固定版本的详细 SOP、工具列表、示例和校验能力。任务结束释放临时上下文，保留恢复与审计所需引用，不等于删除执行证据。

技能包采用 Markdown＋声明式配置组织，包含 SKILL.md、工具依赖、输入输出约束、异常路径、样例与校验脚本。导入时检查来源、完整性、版本及权限要求；脚本进入沙箱，不因技能被管理员导入就成为可信宿主代码。

模糊匹配须澄清或按受限路由处理；工具输出不能指示加载更高权限技能。工具暴露范围同时取技能需要与用户权限的交集，命中技能本身不授权。

## 三、MCP 路由与配置化适配器

| 能力 | 输入与处理 | 边界 |
|---|---|---|
| 工具注册 | 名称、描述、参数契约、风险等级、负责人、授权方式、超时与版本 | 发布前验证契约，禁用后阻止新调用 |
| HTTP 转 MCP | 将获准 REST 接口映射为工具，配置请求/响应字段、错误映射与重试条件 | 固定域名与路径模板白名单，禁止任意 URL、请求头或凭证注入 |
| SOAP 适配 | 显式处理消息模板、命名空间、错误和鉴权 | 不宣称任意 SOAP 可由普通 HTTP 配置自动兼容 |
| 数据库视图工具 | 使用受限账户及批准的只读查询模板，保留行列权限 | 不开放任意 SQL；写操作需专用受审连接器 |
| MCP 协议连接 | 按锁定协议版本适配本地/远程连接与会话 | 外部 stdio Server 不默认作为核心进程内可信插件运行 |

适配器统一调用意图，但不会自动发明业务幂等、事务回滚或客户授权。没有结果核对与幂等能力的写接口标记为受限，按 [03](03-持久化执行与审批恢复.md) 人工收口。

Credential Vault 指凭证保险箱能力边界，不强制某个同名产品。数据库仅存加密材料或引用；根密钥在独立保护路径，备份同时规划恢复方式。网关根据当前用户和目标服务获取适当凭证，在发出请求前注入；模型、技能和诊断包不接触密钥。

不同服务令牌不可任意透传。须校验目标受众、scope 和委托关系，防止网关成为权限代理漏洞。[MCP 授权规范](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/specification/2025-06-18/basic/authorization.mdx)提供了令牌受众与禁止 token passthrough 的相关约束；实施时锁定适用协议版本。

## 四、统一卡片与连接适配

内部 UI Schema 定义文本块、阶段进度、折叠执行摘要、数据确认表、差异、批准/拒绝动作和原文引用。所谓“思考过程”在产品上显示可解释的执行摘要，不输出模型内部思维链。所有动作关联任务与内容版本，不允许前端字段直接覆盖授权事实。

Feishu Adapter 将其映射为经验证的飞书卡片能力（含适用 CardKit 能力），DingTalk Adapter 映射互动卡片，企微按支持范围适配。能力不支持时降级为状态消息和受控页面，不移除审批或泄露附件；流式更新处理频率限制和消息版本冲突。

渠道支持矩阵必须分别记录：应用类型、消息事件、卡片动作、身份映射、长连接/Stream、Webhook、流式更新和附件权限。飞书提供免公网接收地址的长连接能力，但仍需网络访问；不能据此推定所有平台与事件都可同样接入。[飞书官方更新说明](https://open.feishu.cn/changelog?abilityType=Tool&lang=zh-CN)

长连接由企业侧主动建立；集群下按应用凭证管理连接所有权、重连和接管，并统一做事件去重。Webhook 使用签名校验、防重放与持久化接收；收到事件先安全落库再异步处理。两种入口共享业务链路，模式切换不能同时重复派单，也不单凭并发量自动选择 Webhook。

## 五、模型网关与能力协商

网关面向客户获准的模型服务，支持本地与外部端点，按数据边界、质量、复杂度和预算路由。以 OpenAI 兼容接口作为接入目标，vLLM、Ollama、MindIE 或一体机是候选服务，不保证其每个版本与每种 API 完全等价。

逐项探测并认证文本、流式响应、工具调用、结构化输出、Embedding 与错误语义。缺少能力时使用经过评测的适配或拒绝对应任务，不默默退化为无法验证的文本动作。大小模型路由依赖业务样本评测，本地推理仍统计硬件与运维成本。
