# 验证业务不变量

1. 确定基线：读取 [AGENTS.md](../../../AGENTS.md) 与 [测试规则](../../rules/testing.md)；记录待测变更与环境。
2. 选择场景：关联 T/V 编号；读取实现及消费者；区分已实现、待实现和未认证能力。
3. 构造反例：优先暴露受影响的权限泄露、重复副作用、版本错配或错误伪成功。
4. 执行检查：使用真实仓库命令；数据库语义使用对应数据库；隔离外发与生产写入。
5. 判定结果：逐项给出通过、失败或未运行；标出复现步骤、实际行为与预期差异。
6. 收束验收：纯验收任务不顺手修实现；明确请求修复时修复后重跑相关检查。

拒绝用 mock 成功证明事务正确，用格式检查证明业务完成，或删除失败断言换取通过。
