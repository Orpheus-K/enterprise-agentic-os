# 实现最小闭环

1. 定位范围：读取根目录 [AGENTS.md](../../../AGENTS.md)、[代码规则](../../rules/code.md)；涉及接口、状态或权限时读 [架构规则](../../rules/architecture.md)。
2. 对齐契约：定位相关 R/A 编号、现有入口与消费者；明确输入、输出、失败状态及完成条件。
3. 复用能力：搜索既有组件、驱动与成熟上游；只补缺口，不堆备选实现。
4. 实现变化：保持模块所有权、强类型与单一路径；未定义的情况显式报错，不猜测业务默认值。
5. 验证结果：按 [测试规则](../../rules/testing.md) 检查受影响行为；更新必要的契约、调用方与文档。
6. 交付证据：说明改动、验证与未完成项；达到验收即停止。

遇到业务含义无法确定时，保留已完成的独立工作，只澄清阻塞点；不以兼容层同时实现相互冲突的行为。
