# 修复根因并保持可恢复

1. 固定证据：读取 [AGENTS.md](../../../AGENTS.md) 与 [维护规则](../../rules/maintenance.md)；记录版本、症状与影响范围。
2. 定位边界：核对任务状态、授权、租约、事件及外部操作结果；区分失败与结果未知。
3. 最小修复：复用 [代码规则](../../rules/code.md)；修正责任模块，不增加吞错、盲重试或客户专属分支。
4. 证明恢复：按 [测试规则](../../rules/testing.md) 验证复现与回归；升级时加验数据和在途任务兼容。
5. 准备交付：形成补丁、适用版本、恢复步骤与验证证据；仅执行已授权环境内的动作。
6. 更新真源：同步必要决策、支持范围与已知限制；不复制客户诊断内容到共享知识。

外部写结果不明时先核对；旧版本不兼容时停止直接回退；证据不足时说明缺口，不宣称已修复。
