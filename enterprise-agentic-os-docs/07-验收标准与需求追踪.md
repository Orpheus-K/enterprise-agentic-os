# 07 验收标准与需求追踪

## 一、总述：用可复核证据判断交付

验收同时检查业务结果、安全边界、异常恢复和可维护性。演示成功不能替代权限负例与故障测试；规划完成也不代表产品已实现。本篇全部测试均为未来产品验收要求，不是已执行的产品测试结果。

R 编号对应 [03 功能需求](03-产品能力与功能需求.md)，T 编号对应本篇场景。优先级 P0 表示进入相关业务阶段的阻断要求，P1 表示规模化增强，P2 表示集团扩展；涉及安全的底线在任何实际启用阶段均不可降级。

## 三、验收场景与证据

测试准备：使用至少两个不同组织/租户、不同客户权限的销售、合法主管、无审批权人员、含无权成员的群，以及可观察调用结果的测试业务系统。准备正常、缺失、冲突、撤权和提示注入资料；禁止以真实客户外发作为测试副作用。

| 编号 | 场景与操作 | 通过条件与证据 |
|---|---|---|
| T01 正常报价与边界核算 | 使用已知产品、数量与价格，分别计算高于、等于和低于八折的报价；测试零标准价与缺失价格 | 结果与独立计算一致；等于八折不因本条特批，缺失/非法数据转核对；文件与来源、公式、版本一致 |
| T02 七五折特批 | 触发 0.75 折扣，检查卡片与执行状态 | 形成持久化待审批；展示有权限的背景、差异、毛利和来源；批准前无正式受限动作 |
| T03 修改后批准 | 主管调整单价并批准，随后提交旧卡片 | 产生新版本、重新核算；超权限重新审批；旧卡片无效；最终执行与批准版本一致 |
| T04 拒绝、过期与无权批准 | 分别拒绝、超时、使用无权人或失效代理提交 | 不自动批准；状态和通知正确；修订重新申请；保留拒绝与过期记录 |
| T05 长等待与重启 | 审批等待跨越进程重启，三小时后提交有效批准 | 不依赖原进程存活；任务与批准版本保持一致；从正确步骤恢复 |
| T06 未知写结果与恢复 | 业务写入成功但响应丢失；分别在写入前后中断运行 | 先核对再推进，无重复建单；无法核对时停在待核对；证据能说明业务实际状态 |
| T07 重复与伪造回调 | 重复消息、回调及旧版本提交；使用伪造来源 | 只产生一次有效业务动作；伪造或过期请求被拒绝并留痕 |
| T08 权限与撤权 | 无权用户检索；运行与等待期间撤权；测试索引和缓存尚未更新 | 文档、切片、标题及缓存均不泄露；后续敏感动作重新授权，不靠旧结果继续交付 |
| T09 群聊和租户隔离 | 同题在不同租户查询；交付前加入无权群成员 | 不读取其他租户；群中无敏感正文、附件或预览；采用有权限的交付路径或停止 |
| T10 混合分析与证据 | 查询流失率并关联客诉；添加冲突或不足证据 | 使用批准指标口径和行列权限；原文、表格/PDF 定位正确；推断有标识，证据不足不编造 |
| T11 文档等级与用章 | 只请求初稿；批准后请求正式文件；取消用章权 | 初稿清楚标识；审批通过不自动等于签章/外发；无授权不加公章水印；交付版本可追溯 |
| T12 注入与隔离 | 文档要求绕过审批；脚本尝试访问宿主机、内网、凭证及超量资源 | 不改变授权或强制步骤；越界受阻；资源超限可中止；其他任务不受影响 |
| T13 路由、限流和预算 | 本地任务、获准外部任务、模型故障和配额耗尽 | 路由遵守数据边界；不因故障将受限数据外发；超限行为符合配置；成本有来源 |
| T14 首次部署与渠道断连 | 在满足出网前提的内网安装，配置渠道并完成首单；模拟断连 | 不要求暴露业务公网入口；重连后不重复副作用；分别记录安装、授权和首单耗时 |
| T15 无副作用回放 | 使用含写入、发信、审批和用章步骤的历史样本评测 | 真实业务系统与接收方均无变更；报告有样本、基线、候选版本和差异；权限样本合法 |
| T16 发布与回滚 | 发布候选，保留旧版在途任务，再回滚并停用问题版本 | 新任务版本正确；在途版本和当前授权可追溯；停用阻止新任务，安全问题可暂停旧任务 |
| T17 示范和纠错 | 从带敏感字段的示范生成技能；人工修改草稿 | 仅生成待审候选；脱敏与规则缺口可见；Diff 经分类审核进入改进，不自动上线 |
| T18 绩效口径 | 混入重复、失败、取消、测试和正常审批任务 | 各类口径可复算；审批与纠错分开；工时估算有基线，示例数字不冒充真实成果 |
| T19 审计与连接治理 | 停用工具、变更凭证、触发限流并模拟审计不可用 | 停用工具不再调用，密钥不进入模型/日志；关键事件可关联；审计不足时高风险动作停下 |
| T20 迁移、灾备与兼容 | 从轻量迁移到目标生产形态，保留待审批和未知结果任务；演练故障与回退 | 技能、权限、状态和审计连续；无新旧双写；恢复满足约定目标；集团指定环境逐项验证 |
| T21 技能路由与自主边界 | 多技能匹配、无匹配、工具停用、计划超限 | 澄清或转人工；只加载必要且获准技能/工具；不能跳过红线；记录质量与上下文成本对照 |
| T22 取消与补偿 | 分别在写入前、写入后、文件生成失败及发送后取消 | 阻止未执行动作；已执行动作按能力补偿或人工处理；不虚报撤回，不重复写入 |
| T23 垂类套件 | 对产研、合同、外贸分别执行一条正常路径与一条异常路径 | 证据来源、审批和人工边界明确；接入权限与订阅前提列清；外发或生产修改受控 |

每项测试保存输入与授权条件、版本、预期结果、实际结果、执行记录和业务系统核对证据。业务负责人确认业务正确性，安全负责人确认权限与风险，运维负责人确认恢复与部署；未解决的关键安全或重复副作用失败阻断上线。

## 四、风险假设与待决策事项

| 编号 | 假设或待定项 | 验证方式与责任角色 | 影响与默认处理 |
|---|---|---|---|
| H01 | 目标企业因权限、可靠性和维护问题愿意迁移；竞品存在对应缺口 | 产品/售前访谈，按版本与部署模式实测比较 | 不宣称市场已全面迁移或竞品必然缺失能力 |
| H02 | 渐进式加载可节省 80% 上下文 | 技能维护者用同任务集对照质量、Token、耗时和成本 | 百分比仅作假设，不写入承诺 |
| H03 | 本地小模型“零成本”且可承担简单任务 | 运营与评测负责人统计资源、运维和任务质量 | 按总成本衡量；不得使用零成本结论 |
| H04 | 十分钟启动、90% 用户受公网配置阻碍 | 产品负责人观察真实上手路径，分阶段计时和访谈 | 无公网入口为体验方向；时长与比例待验证 |
| H05 | 所有结论都能逐句引用 | 知识负责人检查事实、计算和推断的证据覆盖 | 要求事实与关键结论可追溯，不制造引用 |
| H06 | 看板示例足以证明节省 2.5 人力、修改率下降等收益 | 业务负责人建立同口径人工基线与实测窗口 | 示例数据不作宣传事实，工时不等于裁岗 |
| H07 | 渠道均支持一致的长连接、流式卡片和审批交互 | 集成负责人按应用类型、权限及渠道能力验收 | 飞书先交付；其余能力按实测公布，不假定完全一致 |
| H08 | 权限同步能满足撤权时效；群成员权限可验证 | 安全与数据负责人明确来源能力并进行撤权测试 | 不可确认则拒绝访问或采用受控链接 |
| H09 | 客户报价、代理审批、签章规则已确定 | 业务及法务责任人确认折扣口径、毛利红线、有效期和用章范围 | 八折仅为贯穿示例；缺失正式规则不进行生产审批 |
| H10 | 生产容量、可用性、恢复时间与数据损失目标 | 业务/运维共同确认负载和演练结果 | 本版不承诺数值；生产采购前须写入交付标准 |
| H11 | 历史回放样本可合法用于评测和改进 | 数据与安全负责人确认用途、脱敏、保留期和样本代表性 | “一个月 500 条”为示例；未经批准不使用 |
| H12 | 第三方工具、资信数据与国产环境可接入 | 集成与交付负责人确认授权、契约和兼容测试 | 名称仅表明目标对象；未验证不列为已支持 |
| H13 | 客户认可套件、计费与服务边界 | 商业负责人通过试点反馈与合同评审确认 | 无固定价格、日期和人力回报承诺 |

这些事项是后续客户发现与产品验证任务，不阻碍本轮文档交付；涉及真实生产安全、规则或合同承诺的事项，必须在相应阶段上线前完成确认。

## 五、文档验收与闭环结论

文档本身须满足：八篇文件齐全；均有总述、展开和收束；相对链接有效；R01—R20 均有角色、触发、行为与验收条件；原始五层架构、三级演进、四项商业化能力和示例场景均有来源映射；技术示例未被写成强制选型；量化假设未被写成既成事实。
